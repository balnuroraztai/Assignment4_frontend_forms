# Assignment 4 – Frontend Forms

## Description
This project contains five tasks focused on creating HTML forms and implementing form validation using HTML5, CSS, Bootstrap 5, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Tasks

### Task 0 – Contact Form
A simple contact form with name, email, and message fields, styled using HTML and CSS.

### Task 1 – HTML5 Form Validation
A contact form that uses built-in HTML5 validation for required fields.

### Task 2 – Bootstrap Contact Form
A responsive contact form designed using Bootstrap 5.

### Task 3 – Bootstrap Form Validation
A contact form with JavaScript validation and Bootstrap feedback styles for valid and invalid inputs.

### Task 4 – Registration Form
A registration form with first name, last name, email, password, confirm password, gender, hobbies, and country fields. JavaScript is used to validate the form and check whether the passwords match.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation menu to switch between tasks.
